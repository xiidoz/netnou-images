# netnou-images

Pictures shown in the pull requests and issues of [xiidoz/netnou](https://github.com/xiidoz/netnou).

They are kept here and not in that repository so that they do not become part of its history. Each release holds the pictures of one pull request or issue and is named after it: `pr-51`, `issue-46`. The pictures are the files of the release; there is no code here.
